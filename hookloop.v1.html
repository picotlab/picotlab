How it works

Each candidate is a list of stitch counts per round. A fast model turns counts into a silhouette: a round of n single crochet has circumference n stitch widths, and consecutive rounds sit one stitch height apart. Rounds that grow faster than one stitch height can absorb would ruffle, so they are penalised.

A genetic search mutates counts (add or drop stitches, hold a round, snap to multiples of the ring) and keeps the patterns that match the target with the fewest awkward rounds. The winner is rebuilt stitch by stitch as a spring network (each stitch linked to its neighbours and to the stitch it was worked into) and relaxed with optional stuffing pressure, so ruffles and puckers show up on their own.

Exports the hooked shape as it is now (relaxed and stuffed). Script: in Blender 2.8 or newer open Scripting, press New, paste, then Run Script. It builds the mesh with a yarn material and a subdivision modifier. OBJ: save the text as hookloop.obj, then File › Import › Wavefront (.obj).

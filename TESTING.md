# Help test it

Picotlab is an early prototype, and we want to know how it works for real crocheters.

1. Open `index.html` in a browser (or the hosted copy, if you were given one).
2. Paste the line you're stuck on, or a whole pattern, into "Explain a line".
3. Tell us how it went with the [I tried it](../../issues/new?template=tried-it.yml) issue form.

Things to know:

- Paste only your own text, or a line short enough to quote. Please don't paste whole copyrighted patterns.
- "It didn't help" and "it was wrong" are useful answers. We would rather hear them.
- Some patterns are not explained yet, such as symbol charts and multi-size counts. If yours is one of
  those, say so in the form.
- If you try a design, a measured swatch beside the predicted size is worth the most.

We can't promise a fix or a reply for every report, but each one is read.
